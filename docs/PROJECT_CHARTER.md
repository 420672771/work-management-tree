# 工作管理树项目章程

## 项目基本信息

- 决策人：科技产品中心负责人
- 试点部门：科技产品中心
- 产品/管理 PM：科技产品中心负责人
- 开发与技术负责人：Codex
- 部署：本地
- 版本：V1.2 MVP

## 目标

把例会和日常指令转化为可追踪任务；每个任务只有一个最终责任人；责任人自行组织内部协同；管理者通过时间、交付物、风险和验收完成督办。

## 成功标准

责任人完整率≥95%，接单率≥90%，验收率≥95%，逾期任务升级覆盖率100%。试点阶段不直接将画像用于绩效。

## 范围

一期包含管理树、任务闭环、AI 任务草稿、基础看板、本地部署和企业微信适配层。微信凭据配置前，消息服务保持 dry-run。
