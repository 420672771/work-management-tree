# MVP 测试与验收计划

## 自动化测试

- 数据库初始化和种子数据；
- AI 草稿必须人工确认；
- 任务缺少责任人或交付标准时拒绝创建；
- 超期计算；
- 任务反馈和风险状态回写；
- 验收通过和驳回；
- 企业微信未配置时只 dry-run。
- 企业微信回调签名校验、AES 解密和 `任务#编号` 反馈关联。

## 手工验收场景

1. 创建责任域和责任事项。
2. 创建任务并指定唯一责任人。
3. 责任人接单、反馈、提交完成。
4. 验收通过后任务关闭。
5. 验收驳回后任务回到执行状态。
6. 截止时间临近和超期显示正确。
7. 风险反馈进入看板。
8. AI 无法识别时间时仍必须人工确认。

## 上线门禁

自动化测试全绿、核心流程手工验收通过、数据备份可恢复、企业微信凭据完成独立环境验证后，才允许启用真实消息发送。
