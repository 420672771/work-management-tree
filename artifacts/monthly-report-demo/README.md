此目录为独立演示数据库中的虚构员工和任务，不含线上月报。

运行 `python3 scripts/demo-monthly-report.py`，默认生成上一个自然月的 5 位员工、6 份月报版本。

站点入口：`/monthly-report-demo`；也可从“个人月报”的登录提示内点击演示入口。

- 林晓：P0 重点工作、不同优先级完成事项；已归档。
- 陈晨：逾期、阻塞与资源协调；可编辑草稿。
- 周宁：V1 归档、V2 修订；可对比历史版本。
- 赵悦：待验收超时、进行中及下月计划；可编辑草稿。
- 孙然：无正式任务；保留统计为零并手工补充总结与计划。
- 部门负责人、管理 PM：查看全部员工，他人月报只读。

网页复用实际月报界面；演示 API 仅在当前页面模拟，编辑及后续操作只写浏览器 sessionStorage，关闭标签页后结束演示；“恢复初始演示”可清除本次修改。生产月报接口仍要求真实员工登录。

index.html 是演示入口，依赖站点提供的 /static/monthly-reports.js；report.json 包含生成的虚构快照与模拟操作记录；demo.db 是可重复生成的演示数据库，已排除版本控制。preview.png 为演示截图，example.svg 为导出示例。
